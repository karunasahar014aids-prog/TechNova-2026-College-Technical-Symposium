# TechNova 2026 – College Technical Symposium

A responsive event registration website developed as an academic activity using HTML, CSS and JavaScript.

## Features
- Home page and event introduction
- Event details, date, venue and schedule
- Responsive navigation
- Online registration form
- Mandatory field validation
- Email and 10-digit mobile validation
- Registration success message
- LocalStorage-based registration data management
- Mobile responsive layout
- Contact section

## Technology
HTML5 • CSS3 • JavaScript • Browser LocalStorage

## AI Assistance
ChatGPT was used to generate design ideas, suggest HTML/CSS structure and assist with JavaScript validation. The code was reviewed, tested and customized before submission.

## Testing
1. Home page loads correctly
2. Navigation links work
3. Empty mandatory fields show errors
4. Invalid email is rejected
5. Invalid mobile number is rejected
6. Valid registration shows confirmation
7. Registration data is stored in LocalStorage
8. Mobile layout adapts to smaller screens

## Run locally
Open `index.html` in a modern web browser.

## Important
LocalStorage stores demo registration data only in the user's browser. Do not use it for real sensitive participant information.
